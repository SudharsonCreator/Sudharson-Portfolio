## 📸 Overview

**Securitas Portfolio** is a futuristic, dark-themed personal portfolio built for a Cybersecurity & Network Engineering profile. It features cinematic animations, 3D parallax effects, interactive security panels, a scramble text effect, and a real-time mouse glow — all crafted to reflect a high-security aesthetic.

---

## ✨ Features

- 🌌 **Animated Hero Section** — Parallax 3D wireframe model with floating HUD elements
- 🔡 **Text Scramble Effect** — Matrix-style character reveal on hover
- 🖱️ **Magnetic Buttons** — Cursor-following interaction on CTA buttons
- 🃏 **3D Tilt Cards** — Mouse-tracked perspective transform on project and skill cards
- 🔦 **Mouse Glow Crosshair** — Live radial gradient + crosshair that follows the cursor
- 🛡️ **Security Panel** — Interactive easter egg panel with Neutralize / Protect animations
- 📜 **Scroll Progress Bar** — Fixed top progress indicator
- 🌊 **Floating Particles & Data Fragments** — Ambient parallax decorative elements
- 📱 **Fully Responsive** — Mobile-first layout across all sections
- 📬 **Contact Form** — Uplink form with a cinematic success state

## 🚀 Getting Started

### Prerequisites

- Node.js `v18+`
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/SudharsonCreator/securitas-portfolio.git
cd securitas-portfolio

# 2. Install dependencies
npm install

# 3. Copy environment file
cp .env.example .env

# 4. Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm run preview
```
